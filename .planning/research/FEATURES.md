# Feature Research

## Table Stakes

- Stable schema identifiers and explicit versions.
- Shared definitions for repeated metadata.
- Valid examples and automated validation.
- Compatibility policy and changelog discipline.
- CI on multiple operating systems.

## Differentiators

- End-to-end lifecycle fixture spanning all contracts.
- Mandatory W3C trace context and correlation identifiers.
- Explicit policy, verification, and evaluation evidence models.

## Deferred

- Generated SDKs, registries, package publication, and remote schema service.
